# 注释范围

手写源码、Vite 配置和测试中的模块职责、变量、参数、函数、回调、组件 props 及生命周期说明均按实际用途维护。组件与调用方分别说明 loading、取消、身份代次、资源清理和失败反馈责任；类型和声明数量只用于定位，不能代替准确性审查。

模板局部变量与回调说明靠近所属组件；样式变量注明主题、安全区或布局用途。JSON 配置、锁文件、图像及生成的依赖、构建产物保留工具格式，不插入人工逐行说明。字体和第三方许可证保留原文。

脚本 AST、模板编译结果及样式声明都需要保持语义一致。单元测试与生产构建证明本地框架链路，真实后端、宿主 Bridge 和设备浏览器仍属于独立环境验收。
